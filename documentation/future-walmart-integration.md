# Future Walmart Integration

The MVP implements `RetailerAdapter` search-link adapters for Walmart, Publix, Kroger, and Instacart. These only build safe product-search URLs.

Future work may add official partner API product search, preferred product mapping, and cart preparation only after authorized integration credentials are configured. Do not store retailer passwords, automate login, bypass bot protections, scrape restricted pages, or automate checkout.
